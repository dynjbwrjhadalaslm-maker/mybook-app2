MyBook PWA — ফোনে ইনস্টল করার নির্দেশনা
==========================================

⚠️ গুরুত্বপূর্ণ: PWA ইনস্টল অপশন কাজ করার জন্য অ্যাপটা অবশ্যই HTTPS-এ
হোস্ট করা থাকতে হবে (ফাইল সরাসরি ফোনে খুললে ইনস্টল বাটন দেখাবে না)।
সবচেয়ে সহজ ও ফ্রি উপায় হলো GitHub Pages।

ধাপ ১: Firebase কনফিগ বসান
---------------------------
index.html ফাইলে "YOUR_API_KEY" ইত্যাদি জায়গায় আপনার Firebase
প্রজেক্টের আসল তথ্য বসান (আগেই বলা হয়েছিল কীভাবে বানাবেন)।

ধাপ ২: GitHub-এ আপলোড করুন (ফ্রি)
-----------------------------------
1. https://github.com -এ অ্যাকাউন্ট খুলুন
2. একটা নতুন Repository বানান (নাম দিন যেমন: mybook-app)
3. এই ফোল্ডারের সব ফাইল (index.html, manifest.json, service-worker.js,
   icon-192.png, icon-512.png) সেই Repository-তে আপলোড করুন
4. Repository → Settings → Pages -এ যান
5. "Branch" থেকে main সিলেক্ট করে Save করুন
6. কিছুক্ষণ পর একটা লিংক পাবেন, যেমন:
   https://আপনারইউজারনেম.github.io/mybook-app/

ধাপ ৩: ফোনে ইনস্টল করুন
-------------------------
সেই লিংকটা ফোনের Chrome ব্রাউজারে খুলুন। উপরে ডানদিকে
"📲 ইনস্টল করুন" বাটন দেখাবে — চাপ দিলেই এটা ফোনের হোম স্ক্রিনে
আসল অ্যাপের মতো আইকন হয়ে বসে যাবে, এবং খুললে ফুল-স্ক্রিন অ্যাপ
হিসেবে চলবে (ব্রাউজারের অ্যাড্রেস বার থাকবে না)।

আইফোনে: Safari দিয়ে খুলে Share বাটন → "Add to Home Screen"
